# Productivity Dashboard

A responsive productivity web application built with HTML, CSS, and JavaScript. It brings everyday planning and focus tools together in one dashboard.

## Features

- **Todo List:** Add tasks, mark them complete or important, and delete them.
- **Daily Planner:** Organize your day using hourly time slots.
- **Daily Goals:** Track goals and monitor completion progress.
- **Pomodoro Timer:** Manage focused work sessions with Start, Pause, and Reset controls.
- **Motivation Quotes:** Fetch inspirational quotes from an API.
- **Weather Widget:** View current weather information.
- **Live Date & Time:** Display the current date and clock.
- **Dynamic Background:** Change the background according to the time of day.
- **Light/Dark Theme:** Switch themes and remember your preference.
- **Local Storage:** Preserve supported data after refreshing the page.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation and Event Listeners
- Browser Local Storage
- Fetch API
- Date Object and `setInterval()`

## Getting Started

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser, or use the Live Server extension in VS Code.
4. Allow location access if prompted by the weather widget.

An internet connection is needed for live weather and quote requests.

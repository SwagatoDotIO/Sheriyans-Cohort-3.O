# DOM Task Manager

A basic Task Manager project built using HTML, CSS and Vanilla JavaScript.

The main purpose of this project is to practice DOM manipulation, attributes, properties and event handling.

## Features

- Add new tasks
- Add task categories
- Edit tasks
- Complete tasks
- Delete tasks
- Light and dark theme
- Event delegation
- Event bubbling
- Event capturing
- DOM manipulation using JavaScript

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM API

## DOM Concepts Used

This project demonstrates:

- `createElement()`
- `createTextNode()`
- `append()`
- `appendChild()`
- `prepend()`
- `before()`
- `after()`
- `replaceWith()`
- `remove()`
- `getAttribute()`
- `setAttribute()`
- `removeAttribute()`
- `hasAttribute()`
- `dataset`
- `classList`
- Event Delegation
- Event Bubbling
- Event Capturing
